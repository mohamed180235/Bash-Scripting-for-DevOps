# Lecture 1 — Bash Basics

## Learning objectives
- Identify the active shell and compare shell invocation methods.
- Understand shebangs and script execution.
- Set file permissions safely.
- Create and expand variables.
- Distinguish shell variables from exported environment variables.
- Collect user input using `read`.
